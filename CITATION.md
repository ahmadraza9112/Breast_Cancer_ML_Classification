# Source credit and scientific scope

- Dataset: [Breast Cancer Wisconsin (Diagnostic), UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic).
- Dataset bundled in scikit-learn: [`sklearn.datasets.load_breast_cancer`](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_breast_cancer.html).
- scikit-learn citation: Pedregosa F, et al. **Scikit-learn: Machine Learning in Python.** Journal of Machine Learning Research 12 (2011), 2825–2830.

**Important distinctions:** This package does not redistribute original images; it uses numerical features from the standard bundled dataset. Its results are intended for education, not for clinical diagnosis.
